How to test

  1. Change a setting in Alibi, then reload this page (or press Reload to apply in the popup).
  2. Try the hardest case, HTML that arrives instantly: ?delay=0. Then a normal network delay: ?delay=150.
  3. Give localhost its own cover in the popup. Both iframes should follow this page, not their own address.
  4. Stealth: expect the Web Worker and new blank iframe to show your real zone. With “Allow User Scripts” off, the iframes and the first inline script can too. Deep: every row should match.
  5. Open the same page on the other site to swap which address is the cross-site one.
